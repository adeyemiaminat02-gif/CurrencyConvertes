# Telegram Currency Converter Bot (@CurrencyConvertesbot)

A production-ready Telegram Currency Converter Bot written in Python 3.12 using `python-telegram-bot` (v22+), `SQLAlchemy` (Async), and `httpx`.

## 🚀 Features
- **Natural Language Parsing**: Convert inputs like `100 USD to EUR` directly.
- **Over 150+ Currencies**: Real-time rate calculation powered by ExchangeRate API.
- **Interactive Buttons**: Swap and Refresh currencies dynamically via inline buttons.
- **Conversion History**: Automatic background recording of your last 10 conversions.
- **Async & Fast**: Built with non-blocking async architecture and TTL caching.
